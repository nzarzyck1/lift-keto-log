LIFT + KETO

Nathan's food, lift and steps log

Download the app
  1. Tap Download the app above. If Chrome warns that the file might be harmful, tap Download anyway.
  2. Open the downloaded file. The first time, Android asks to allow installs from Chrome: tap Settings, turn on Allow from this source, then go back.
  3. Tap Install. If Play Protect asks, tap More details and then Install anyway. This app is private to you, so Google hasn't scanned it.
  4. Open Lift + Keto, go to the Setup tab, connect Samsung Health and add your API key.

You only install once. Changes you ask for show up inside the app on their own. A new install is needed only for rare bigger changes, and the app tells you when.
